LA STORIA

Rapallo, Riviera Ligure. Da settimane in città sparisce gente.
Lara Croft arriva al tramonto, sulle tracce di un nome trovato in un vecchio
diario: Cavassa. Il diario parla di una porta rossa, sulla montagna.

Alcune porte andrebbero sempre lasciate chiuse.

I luoghi del gioco esistono davvero: le mappe sono costruite sui dati di
OpenStreetMap e sulle foto scattate sul posto.

I LIVELLI

  1. Il Castello sul Mare
  2. Il Santuario di Montallegro

INSTALLAZIONE

  1. Estrai tutto l'archivio in una cartella a tua scelta, mantenendo la
     struttura delle cartelle (non serve installare niente).
  2. Avvia il launcher (il file .exe nella cartella principale).
  3. Non serve avere Tomb Raider originale: il gioco è completo.
  4. Il filmato iniziale e quello finale sono file .wmv nella cartella
     FMVs: se non partono, controlla che Windows Media Player sia
     installato (su Windows N va aggiunto il Media Feature Pack).

REQUISITI

  - Windows
  - Il gioco gira sul motore di Tomb Raider: The Last Revelation con TRNG,
    quindi va bene praticamente su qualsiasi PC.

COMANDI

  Comandi standard di Tomb Raider 4 / TRNG. Si possono cambiare dal menu
  Opzioni > Controlli.

SALVATAGGI

  I salvataggi finiscono nella cartella del gioco. Se reinstalli, copiali
  prima di cancellare la cartella vecchia.

THE STORY

Rapallo, on the Italian Riviera. People in town have been disappearing for
weeks. Lara Croft arrives at sunset, following a name found in an old diary:
Cavassa. The diary speaks of a red door, up on the mountain.

Some doors should always stay closed.

Every location in the game is real: the maps are built from OpenStreetMap
data and from photos taken on site.

THE LEVELS

  1. Il Castello sul Mare ........... The Castle by the Sea
  2. Il Santuario di Montallegro .... The Montallegro Sanctuary
  3. La Chiesa Profanata ............ The Desecrated Church
  4. Infiltrazione Notturna ......... Night Infiltration
  5. Il Rito in Nero ................ The Black Rite
  6. La Torre nella Pioggia ......... The Tower in the Rain
  7. La Messa Nera .................. The Black Mass
  8. L'Avvertimento Apocalittico .... The Apocalyptic Warning
  9. Le Fondamenta .................. The Foundations
 10. La Lama di Luce ................ The Blade of Light
 11. Evacuazione .................... Evacuation
 12. La Porta Rossa ................. The Red Door
 13. La Cattedrale di Carne ......... The Cathedral of Flesh

INSTALLATION

  1. Extract the whole archive to any folder, keeping the folder structure
     (no installation needed).
  2. Run the launcher (the .exe file in the main folder).
  3. You don't need the original Tomb Raider: the game is standalone.
  4. The intro and ending movies are .wmv files in the FMVs folder. If
     they don't play, make sure Windows Media Player is installed (on
     Windows N editions you need the Media Feature Pack).

REQUIREMENTS

  - Windows
  - The game runs on the Tomb Raider: The Last Revelation engine with TRNG,
    so pretty much any PC will do.

CONTROLS

  Standard Tomb Raider 4 / TRNG controls. You can change them from
  Options > Controls.

SAVES

  Save games are stored in the game folder. If you reinstall, copy them
  before deleting the old folder.

NOTE FOR NON-ITALIAN PLAYERS

  In-game text and FMV captions are in Italian. The end credits are in
  English.
